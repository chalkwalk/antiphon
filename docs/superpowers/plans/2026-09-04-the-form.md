# The Form Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phrase the listener can recognise coming back -- `AABA` over
sections of several intervals, where a section changes the whole groove and no
harmony at all.

**Architecture:** A `Form` decides, from the room seed and the metre, which
letter each interval belongs to, measured from an origin that resets when the
tune restarts or its harmony moves. A letter is realised as a **density
transformation** of the session's own figures, so B is this tune's idea at a
different weight rather than a different tune. The lead's contour becomes
section-held, which measurement shows makes consecutive lines share ~44% of
their notes and never all of them.

**Tech Stack:** C++17, `chalkwalk-jambot`, `chalkwalk-music` for Euclidean
figures, `AntiphonVoiceLab parity` as the instrument.

**Spec:** `docs/superpowers/specs/2026-09-04-the-form.md`

**Prerequisite, landed:** `performanceSeed`. This is the first change that can
put two identical figures side by side and it is only safe because their
performances now differ (`ROADMAP.md`, the interlock).

## Global Constraints

- **Two repositories.** All code is `libs/jambot`; the parity instrument is
  Antiphon's `AntiphonVoiceLab`. Bump the submodule before calling anything
  done.
- **ASCII only in source files.** `--` for an em dash, `->` for an arrow.
- **2-space indent, braces on the same line, members lowerCamelCase.**
- **No comments except for non-obvious invariants**, explaining *why*.
- **THE AUDIO CHANGES IN EXACTLY ONE COMMIT, Task 5.** Tasks 1-4 are pure
  additions and threading with an identity default, and each must leave

- **Run every build and tool from the repository root with absolute paths.** A

  branch one false "all four voices changed" panic.
- **Capture the baseline first:**
  `AntiphonVoiceLab parity --key "C major" > /tmp/form-before.txt`

- [ ] **Step 3: Write `Form.h`**

```cpp
#pragma once

#include <cstdint>
#include <string>

// Structure above the interval: which section of the tune an interval belongs
// to. Knows nothing about figures or voices -- what a section CHANGES is
// BotBand's business, and what a section IS is this.
//
// Designed in Antiphon's docs/superpowers/specs/2026-09-04-the-form.md.
namespace Form {

// AABA, ABAC or AAAB, from the room seed -- so `shake` reaches the shape of the
// music and not only its notes.
std::string table(std::uint32_t seed);

// How many intervals a section lasts, from a DURATION rather than a count: the
// seed picks a target of roughly twenty to forty seconds and the metre converts
// it, so a section feels like a section whatever the room's tempo.
//
// Never one, and that bound is not taste. A listener hears the band an interval
// late, so a one-interval section is a whole section out of step in their ear,
// where at N it is 1/N. Never more than eight, because eight intervals of one
// letter at a slow metre stops being a section and becomes the tune.
int intervalsPerSection(std::uint32_t seed, int bpm, int bpi);

// Which letter `intervalIndex` belongs to, as an index where 0 is A.
//
// Measured from `origin`, which is the interval the form last restarted at --
// a tune starting, or its key, chart, tempo or metre moving. An interval at or
// before the origin is the first interval of the first section: a reset that
// walked backwards would play a letter nobody had heard yet.
int letterAt(std::uint32_t seed, int bpm, int bpi, int origin,
             int intervalIndex);

} // namespace Form
```

- [ ] **Step 4: Write `Form.cpp`**

```cpp
#include "Form.h"

#include <algorithm>
#include <cmath>

namespace Form {
namespace {

// The same xorshift the band uses, so a form drawn from a seed and a figure
// drawn from it behave alike.
struct Rng {
  std::uint32_t state;
  explicit Rng(std::uint32_t s) : state(s | 1u) {}
  std::uint32_t next() {
    state ^= state << 13;
    state ^= state >> 17;
    state ^= state << 5;
    return state;
  }
};

} // namespace

std::string table(std::uint32_t seed) {
  static const char *kTables[] = {"AABA", "ABAC", "AAAB"};
  Rng r(seed ^ 0xF0F17Au);
  return kTables[r.next() % 3];
}

int intervalsPerSection(std::uint32_t seed, int bpm, int bpi) {
  if (bpm <= 0 || bpi <= 0)
    return 2;
  Rng r(seed ^ 0x5EC7104u);
  const double target = 20.0 + (double)(r.next() % 21); // 20..40 seconds
  const double intervalSeconds = (double)bpi * 60.0 / (double)bpm;
  const int want = (int)std::lround(target / intervalSeconds);
  return std::max(2, std::min(8, want));
}

int letterAt(std::uint32_t seed, int bpm, int bpi, int origin,
             int intervalIndex) {
  const auto t = table(seed);
  if (t.empty())
    return 0;
  const int since = intervalIndex - origin;
  if (since <= 0)
    return 0;
  const int n = intervalsPerSection(seed, bpm, bpi);
  const int section = since / n;
  return t[(std::size_t)(section % (int)t.size())] - 'A';
}

} // namespace Form
```

```cpp
int pulsesFor(int basePulses, int lo, int hi, int letter, std::uint32_t seed) {
  if (letter <= 0 || hi <= lo)
    return basePulses;

  // Per LETTER rather than per section, so ABAC's B and C are two densities
  // rather than one coin flipped twice.
  Rng r(seed ^ (0xD315A7u + 6151u * (std::uint32_t)letter));
  const int magnitude = 1 + (int)(r.next() % 2); // one or two pulses
  const int direction = (r.next() % 2) ? 1 : -1;

  int p = basePulses + direction * magnitude;
  if (p < lo || p > hi)
    p = basePulses - direction * magnitude; // reflect off the edge
  p = std::max(lo, std::min(hi, p));

  // A range too narrow to move in leaves the figure alone rather than
  // pretending: better one letter that sounds like another than a figure
  // outside what the voice can play.
  return p;
}
```

- [ ] **Step 2: Give the bot an interval index to reset TO**

The four triggers do not have one. `PracticeBot::renderInterval(numSamples,

So the bot remembers it:

```cpp

  // thread knows where "now" is. Under `stateMutex` with the settings it
  // belongs to, because a form origin read against a stale interval would
  // restart the form in the past.
```

- [ ] **Step 3: Implement the four triggers**

Set `settings.formOrigin = lastRenderedInterval + 1` in `applyKey`'s and
`applyChart`'s success paths, in `onServerConfig` when bpm or bpi actually
changed, and where `BandPlayState` leaves `Silent`.

**`+ 1`, not the current index.** The interval the pump is rendering has
already been given its letter; restarting at it would change the form under an
interval that is half written. The next one is the first that can start a
section cleanly, and it is also what makes `letterAt`'s `since <= 0` rule read
correctly.

**Guard on actual change.** `onServerConfig` fires with the same values on
join, and a reset there would restart the form for a message that changed
nothing.

## What this leaves

*Deviation* -- an occasional departure whose likelihood grows the longer a
phrase has repeated -- is next in `ROADMAP.md`'s order and now has a form to
depart from. *A shared intensity curve* is the other axis: intensity varies
within a section where the form varies between them.
